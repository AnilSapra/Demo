# Uber Analytics Dashboard

An interactive Streamlit-based Uber Analytics Dashboard for exploring ride booking datasets, visualizing business insights, and performing ride analytics.

---

## Features

### Dataset Exploration
- View total rows, columns, and missing values
- Search data dynamically
- Filter dataset by columns and values
- Download filtered dataset
- Row preview slider

### Dashboard Overview
- Revenue analytics
- Ride performance metrics
- Business unit performance
- Cancellation audit
- Data quality checks

### Ride Analytics
- Sunburst charts
- Treemap visualization
- Sankey flow analysis
- Revenue distribution
- Customer rating analysis
- Booking trends

### Data Assistant
Ask questions like:
- Total rides
- Revenue
- Vehicle analysis
- Payment analysis
- Rating analysis
- Distance analytics

### New Features Added
- CSV file upload support
- Optional extended description field
- Dynamic dataset loading

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Streamlit Option Menu
